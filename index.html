Tentang Coding Club

Coding Club adalah kegiatan ekstrakurikuler yang menjadi wadah bagi siswa untuk belajar dan mengembangkan kemampuan di bidang pemrograman. Melalui Coding Club, siswa dapat mempelajari berbagai bahasa pemrograman, membuat proyek sederhana, serta melatih kemampuan berpikir logis, kreatif, dan problem solving. Kegiatan ini juga dapat membantu siswa mengenal dunia teknologi dan mempersiapkan keterampilan yang berguna untuk masa depan.

Apa yang dipelajari

  • HTML
  • CSS
  • JavaScript
  • Pemrograman Web
  • Git dan Github

Alur Mengikuti Coding Club

  1. Mengisi formulir pendaftaran
  2. Mengikuti pertemuan pertama
  3. Belajar dasar pemrograman
  4. Membuat proyek sederhana
  5. Presentasi hasil proyek

Kegiatan Coding Club

Belajar HTML

Mempelajari dasar-dasar HTML untuk membuat dan menyusun struktur halaman website.

Membuat Website

Membuat website sederhana dengan menerapkan HTML, CSS, dan dasar-dasar JavaScript.

Project Showcase

Menampilkan dan mempresentasikan hasil project website yang telah dibuat oleh anggota Coding Club.
